# Ceylon Journey Co. React Homepage

A responsive React + Vite implementation of the Ceylon Journey Co. homepage concept.

## Run

```bash
npm install
npm run dev
```

Then open the Vite local URL.

## Customize
- Replace the Unsplash image URLs in `src/main.jsx` with your own Sri Lankan photos.
- Change the WhatsApp number and contact details in `src/main.jsx`.
- Connect the Request a Quote form to your backend, email service, WhatsApp API, or CRM.
- The `public/design-reference.png` file is the original visual reference used for the implementation.
